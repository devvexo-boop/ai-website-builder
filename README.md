# ai-website-builder

A lightweight Nova AI sidebar web app focused on chat reset, + actions, uploads, audio recording, quick tools, and small UI/coding help.

## Files
- `index.html` – app layout and sidebar/chat UI
- `styles.css` – dark/light theme styles
- `app.js` – Nova AI behavior and sidebar interactions
- `SIDEBAR_ASSISTANT_SPEC.md` – original behavior specification

## Run locally
Open `index.html` in a browser.
